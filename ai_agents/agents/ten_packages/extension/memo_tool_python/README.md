# Memo Tool Python Extension

备忘录工具扩展，用于创建、查询、更新和删除备忘录，主要用于记录物品位置、重要信息等。

## 功能特性

- **创建/更新备忘录**：记录关键词和内容，如果关键词已存在则自动更新
- **查询备忘录**：支持精确匹配和模糊匹配
- **列出所有备忘录**：可以按分类筛选
- **删除备忘录**：删除指定的备忘录
- **更新备忘录**：更新已存在的备忘录内容

## 工具列表

### 1. create_memo
创建或更新备忘录。

**使用场景**：
- 用户说："帮我记一下，我的车钥匙放在办公室抽屉里"
- 用户说："记住，我的密码是123456"
- 用户说："我的身份证放在钱包里"

**参数**：
- `key` (必需): 记忆的关键词或主题，如"钥匙"、"钱包"、"密码"等
- `content` (必需): 要记忆的内容，如"放在抽屉里"、"123456"等
- `category` (可选): 分类，如"物品位置"、"重要信息"、"联系方式"等
- `session_id` (可选): 会话ID

### 2. query_memo
查询备忘录。

**使用场景**：
- 用户问："我的车钥匙在哪？"
- 用户问："我记的密码是什么？"
- 用户问："钱包放在哪？"

**参数**：
- `key` (必需): 要查询的关键词或主题
- `session_id` (可选): 会话ID

**返回**：
- 如果找到1条：返回详细信息（包括分类和记录时间）
- 如果找到多条：返回列表
- 如果未找到：提示未找到

### 3. list_memos
列出所有备忘录。

**使用场景**：
- 用户问："我的备忘录有哪些？"
- 用户问："我都记了什么？"

**参数**：
- `category` (可选): 筛选分类，留空则列出所有
- `session_id` (可选): 会话ID

### 4. delete_memo
删除一个备忘录。

**使用场景**：
- 用户说："删除钥匙的备忘录"
- 用户说："忘记那个密码"

**参数**：
- `key` (必需): 要删除的关键词
- `session_id` (可选): 会话ID

### 5. update_memo
更新一个已存在的备忘录。

**使用场景**：
- 用户说："更新钥匙的位置，现在在车里"
- 用户说："修改密码为654321"

**参数**：
- `key` (必需): 要更新的关键词
- `content` (必需): 新的内容
- `session_id` (可选): 会话ID

## 数据存储

数据存储在 SQLite 数据库中，位置：`extension/data/memos.db`

## 查询特性

- **模糊匹配**：查询时支持部分关键词匹配
- **多结果处理**：如果找到多个匹配项，会列出所有结果
- **分类筛选**：可以按分类查看备忘录

## 配置

在 `property.json` 中添加：

```json
{
  "type": "extension",
  "name": "memo_tool_python",
  "addon": "memo_tool_python",
  "extension_group": "default",
  "property": {}
}
```

## 依赖

- `python-dateutil>=2.8.0` - 用于时间处理（可选，用于显示记录时间）

## 注意事项

- 如果使用 `create_memo` 创建已存在的关键词，会自动更新为新的内容
- 每个会话的备忘录是独立的（通过 session_id 区分）
- 查询时支持模糊匹配，会返回所有包含关键词的备忘录
